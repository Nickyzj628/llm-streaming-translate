# docs

本目录存放项目的业务文档与流程图。

## 目录约定

- 每个业务（如翻译流程、设置存储、模型列表拉取等）一个子目录或一个 Markdown 文件。
- 流程图使用 Mermaid 语法书写，便于在 GitHub / VS Code / Typora 等工具中直接渲染，也方便新人阅读与维护。
- 业务文档应说明：参与模块、数据流向、关键协议/约定、易踩的坑。

## 文档清单

- [options-模型配置.md](options-模型配置.md) — Options 页面如何配置翻译模型（表单字段、预设、模型列表拉取、测试翻译、导入导出、background 消费侧）。
